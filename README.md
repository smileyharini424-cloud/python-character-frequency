# Character Frequency Analyzer

## Explanation

This program counts how many times each character appears in a given string.

## Problem Statement

Write a Python program to find the frequency of every character in a string.

## Features

* Accepts text from the user
* Counts each character
* Stores frequencies in a dictionary
* Displays the results

## How It Works

The program examines each character one by one. A dictionary stores the character as the key and its frequency as the value.

## Technologies Used

* Python 3

## Data Structure Used

* Dictionary

## Methods Used

* `input()`
* Dictionary
* `get()`

## Program Flow

1. Start
2. Read the string
3. Examine each character
4. Update its frequency
5. Display the frequencies
6. End

## Sample Input

```text
hello
```

## Sample Output

```text
h: 1
e: 1
l: 2
o: 1
```

## Time Complexity

O(n)

## Space Complexity

O(k), where k is the number of unique characters.
